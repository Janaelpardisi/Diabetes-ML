 Diabetes Prediction Using Machine Learning

This project focuses on predicting the likelihood of diabetes in patients using the Pima Indians Diabetes Dataset. Various supervised machine learning algorithms have been applied and compared to find the best-performing model.

📌 Objectives:

Predict diabetes based on medical features.

Compare different ML algorithms for performance.

Use ensemble methods to improve prediction accuracy.


📊 Algorithms Used:

Support Vector Machine (SVM)

Random Forest

Decision Tree

AdaBoost

XGBoost

Voting Classifier (ensemble of top models)


⚙️ Workflow:

Data Cleaning & Preprocessing

Exploratory Data Analysis (EDA)

Feature Scaling & Selection

Model Training and Evaluation (Accuracy, F1-score, Confusion Matrix, ROC-AUC)

Ensemble Modeling
